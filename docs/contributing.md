# Contributing

Follow the repository-level [contribution guide](https://github.com/SM260845/sourcefold-wiki/blob/main/CONTRIBUTING.md) for the complete workflow.

## Local checklist

- Install with `npm ci`.
- Develop with `npm run dev`.
- Validate with `npm run lint`, `npm test`, `npm run format:check`, and `npm run build`.
- Update tests when changing fold behavior.

## Documentation rules

Write for clone users and future contributors. Keep pages factual, short, and task-oriented.
